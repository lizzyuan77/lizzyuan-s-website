Reference results and how these demos run

The buttons reveal consecutive seeded draws generated by the supplied Python code. Play reveals batches; it does not change the population or collect real responses. Bootstrap: 4,000 resamples from one reference poll. Coverage: 2,000 NEW polls, each bootstrapped 4,000 times at 90%, 95%, and 99% confidence. Null: 100,000 polls from a 50–50 population. No polls are selected to make the results look convincing. Exact binomial calculations validate Monte Carlo p-values and calibrate the discrete 5% rejection rule.
